USB 设置

电脑可以直接管理账户、网络和显示设置，无需加入设备热点。先连接 USB，再在设备上选择「设备设置 → USB 设置」打开限时窗口。

连接 USB 后再打开设备上的 USB 设置窗口。

浏览器会先打开串口。设备可能会重启；请等待小屏启动后再打开 USB 设置窗口，然后点击「连接设备设置」。

输入设备设置密钥

先连接设备热点，再输入屏幕第三步显示的完整 43 位密钥。可逐行输入，空格和换行会自动去除。

密钥只用于当前设置窗口，保留在此页面内存中。

账户管理

Passport 保存账户、网络与设置。每个账户使用自己的更新来源。

添加设备账户

在有网络的手机或电脑上批准官方授权，Passport 保存凭证并自行查询额度。

开始后设备热点会关闭。请让手机或电脑接回可用网络，再打开设备屏幕上的官方二维码并输入验证码。此网页不会继续显示授权结果。

只查询人民币余额。保存后等待设备联网验证；已有密钥不会回显。

可选电脑采集器由你手动运行。通过 USB 设置连接后，Claude 账户需在发现后明确导入。

连接个人 Wi-Fi

仅支持 2.4 GHz 个人 Wi-Fi。企业认证网络请使用手机热点。iPhone 必要时开启热点的「最大兼容性」。

设备将在结束设置后连接并验证。连接失败会保留之前的网络配置。同名网络有多个密码时，请指定保存位置。

刷新与显示

全部启用账户使用设备的刷新间隔。电脑采集账户还需要采集器保持运行。

设置窗口由设备按键打开，超时后自动关闭。关闭网页不会取消设备上的授权。任意键亮屏；长按 DOWN 息屏，授权暂停且有效期继续计时。
