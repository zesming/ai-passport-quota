# 变更日志

只记录版本级变化和对用户数据的影响。根 README 描述当前功能与用法。`未发布` 不代表已经发布版本；提交记录和逐次真机验证细节不在这里重复。

## 未发布

### 重设计第五阶段：息屏浅睡眠（POLL 模式）

- 息屏进入 MCU 自动浅睡眠：启用 `CONFIG_FREERTOS_USE_TICKLESS_IDLE`、`CONFIG_PM_SLP_DISABLE_GPIO`、`CONFIG_USJ_NO_AUTO_LS_ON_CONNECTION` 并把 `light_sleep_enable` 设为 `true`。亮屏期间仍持有 `quota_awake` 锁，所以只在息屏时才会睡。
- 息屏顺序：面板 Sleep In → 停按键轮询、暂停并停掉 LVGL 定时器与 tick、背光/LCD CS 睡眠电平 → 释放锁；唤醒顺序相反（先取锁）。息屏期间只有一个 50 ms 的采样定时器读按键 ADC，三个键都能唤醒；唤醒那次按键只亮屏，由 BSP 丢弃事件直到松开（ADC ≥1900 mV 持续 20 ms 也算，覆盖停表时被打断的长按和很短的轻点）。按键初始化失败时息屏降级为只关屏，不进入浅睡眠。息屏不读电量计，亮屏后立即读一次。
- 息屏时插入 USB 可能无法被识别，需先按键亮屏；USB 主机已连接时不进入浅睡眠。
- 新增 `sdkconfig.profiling` 覆盖层：息屏开始和 60 秒后各存一份 PM 锁与 esp_timer 统计，亮屏后重复打印，`tools/pm_profile_delta.py` 算差值得到浅睡眠占比（测量时拔掉 USB，唤醒后再插）。唤醒延迟目标 ≤250 ms。
- 待真机测量：亮屏、旧固件息屏、新固件息屏的 30 秒平均电流，唤醒成功率和延迟（方法见开发指南）。数值测得后补在这里。

### 重设计第一阶段：删除

产品收敛为两种账户：ChatGPT（统计 Codex 用量）和 DeepSeek（人民币余额），都由 Passport 自己联网刷新，不需要电脑常驻任何服务。

- 删除整个电脑端应用及其 CI 任务。固件不再有电脑采集器 HTTPS 客户端、配对令牌、固定证书和 4318 端口逻辑，USB 不再接受 v1 `configure` 帧（返回 `unsupported_version`），也没有 `collector_configure`、`account_activate`、`account_deactivate`、`external_import`、`network_activate` 命令。
- 删除 Claude：Claude 只能由电脑上 Claude Code 的状态栏回调提供数据，设备无法自行刷新。同时删除其图标、素材和只用于这些文案的字形，重新生成两种字号的字体。
- 删除待启用账户、待启用网络和旧电脑端点。满额时直接拒绝新增，提示先移除一个。
- 删除 v1 配置读取、迁移、旧快照缓存和 11 个未使用的公共函数。`migrate_model` 不再存在：没有账户目录的设备按全新设备处理。
- 枚举取值不复用：`provider` 为 Codex = 0、DeepSeek = 2（1 保留），`source` 和 `activity` 只接受 0。NVS 布局不变，已删除字段成为同样大小的保留字节，固件用编译期断言固定 `model_v2` 与观察缓存记录的大小和偏移。
- 文档只用简体中文：`*.zh_CN.md` 合并进同名 `.md` 并删除，去掉语言链接，仓库检查改为禁止这两类内容。开发文档并为一份，删除便携联网设计文档和所有展示已删功能的截图（新截图随后续界面重设计补充）。

### 重设计第三阶段：协议 v3 与统一设置页

- 设置页合并为一个静态文件：热点（HTTP）和 USB（Web Serial）共用，按页面地址的协议选择传输，不再要求回环地址，USB 下页面不发任何网络请求。源码在 `main/setup/`，`npm run build:setup` 生成并提交 `main/setup_page.html`，meta CSP 只放行按哈希计算的一个样式块和一个脚本块，页面在框架中不渲染，设备响应头另加 `frame-ancestors 'none'`。固件只路由 `/` 与 `/api/*`。
- 协议升到 v3：USB 帧 `v:3`，`session_open` 结果、`/api/state` 和所有错误都带 `protocol` 与 `firmware`，页面据此提示“Passport 固件过旧”或“设置页版本过旧”，版本不一致时不显示修改控件。v2 帧返回 `unsupported_version`。
- 命令：新增 `network_remove` 和仅 USB 的 `validate`；删除 `network_scan`、`mode_select`，`codex_launch` 不再是线上命令。状态删除 `pending_accounts`、`network.pending_network`、`accounts[].source`、`source_changed`、`collector`，新增 `protocol`、`firmware`、`validating`、`validation_step` 和每行的 `validation`（待验证、正常、验证失败）。
- 保存与验证分开：保存立即生效、行状态为待验证；一个验证函数 `quota_portable_validate_pending()`（Wi-Fi → DeepSeek 密钥 → ChatGPT 授权）被 USB 的 `validate` 和热点 `setup_close` 共用。USB 验证后会话保持打开，失败的行可直接修改，再验证只处理待验证和失败的行。验证期间修改类命令返回 `busy`，会话到期不中断验证或授权。DeepSeek 密钥保存时即写入凭据（待验证），换密钥后旧密钥不再保留。ChatGPT 授权在内存里排队，验证走到时才占用凭据缓冲。
- 会话：热点基础 10 分钟、USB 基础 2 分钟，每个修改类命令补到至少 5 分钟，总时长上限 20 分钟，`state_get` 不补时。访问码由 43 字符改为 16 位 Crockford Base32（`XXXX-XXXX-XXXX-XXXX`，约 80 bit），连续 5 次错误锁定，直到在 Passport 上重新开启热点设置。
- 发布：`v*` 标签触发 `.github/workflows/pages.yml`，把页面发布到 GitHub Pages（`/` 为最新，`/p<协议版本>/` 保留历史协议）。
- USB 连接顺序改为：插线 → 点“连接 Passport”选串口 → 在 Passport 上打开 USB 设置。打开串口可能让 C3 重启，所以页面先开串口，之后每 1.5 秒重试 `session_open` 直到 Passport 回应；固件在 USB 设置之外不回应；不再等待启动日志。到期后页面自动等待再次打开。
- Wi-Fi 验证状态增加 `saved`：重启后已保存的网络既不算待验证也不算失败，实际连上时变为正常，所选网络被拒绝密码时变为验证失败。修改正在使用的网络时，新凭据只在内存里暂存，验证通过才写入，失败的密码不会让设备掉线或被保存。ChatGPT 授权超时、取消或没有网络时，账户留在队列里（验证失败）等待重试，不再丢失。
- 暂存的新凭据只属于它自己：用旧凭据连上不会把行改成正常；暂存的网络不再被使用时随选用另一个网络一并写入存储，普通保存同一网络或移除它时清除暂存。USB 等待期间被阻塞的写不再关闭串口也不会堆积帧。设备忙于慢请求时帧只是延后：累计 20 秒无回应才视为重启，随后用同一个打开者编号重新打开会话（没重启则原样取回同一个会话），等待中遇到 `session_busy` 等约 6 秒再试。
- 访问码错误次数按“连续”计数，输对一次清零。`session_expired` 是热点和 USB 统一的“设置时间已到”错误码。发布脚本只在协议版本不低于当前根页面时更新根页面。
- 发布前须知：GitHub Pages 的 `github-pages` 环境需要允许 `v*` 标签（见开发指南）。
- 升级数据影响：无。账户、Wi-Fi 和设置的存储布局不变；已保存的 Wi-Fi 重启后显示“已保存”，DeepSeek 在换密钥后、验证通过前保持“待验证”。

### 重设计第四阶段：设备界面

- 设备界面按新的按键语法重做：上/下移动焦点，短按 OK 执行底栏写的操作，长按 OK 一律是返回（主页上是打开菜单），长按不做破坏性操作；设置会话开着时长按下键不息屏，底栏提示原因。界面只有八个：主页（账户卡或欢迎屏）、菜单、热点设置（三页，关闭后显示验证结果）、USB 设置、选项列表（刷新频率、自动息屏）、设备信息、ChatGPT 授权、确认框。菜单为热点设置、USB 设置、刷新频率、自动息屏、设备信息五项，有账户时记住焦点。
- 恢复出厂设置：设备信息里短按 OK，确认框默认停在“取消”，确认后由网络任务清空 portable 存储分区和默认分区的应用命名空间并重启；擦除失败时显示存储错误且不重启。取消 ChatGPT 授权同样经过确认框。
- 状态行按固定优先级只显示最要紧的一条；热点完成设置后的逐项结果（每个 Wi-Fi、每个账户的正常、验证失败、验证中）显示在设备上，也进入主页状态行（“验证失败”或“待验证”）。邮箱在主页上遮蔽为 `a***@mail.com`。
- 所有界面共用一个固定对象池，切换界面只改文本、位置和显示标志，运行时不再创建或删除对象。字体子集重新生成，12 像素字体不再回退到 Montserrat（不再使用刷新图标）。
- 新增主机界面预览 `tools/ui_preview/`：用真实 LVGL 9.5.0、固件的 LVGL 选项（RGB565、240 × 20 局部缓冲、圆角遮罩）渲染 `fixtures.json` 里的全部界面并输出 PNG 和 LVGL 内存峰值；`tests/test_quota_ui_preview.py` 断言每个界面都能渲染且对象数不变。取代原先的 LVGL 结构体替身。主机峰值只是 24 KB 设备池的保守上限，真机 `lv_mem_monitor().max_used` 仍须实测。
- 评审后的修正：热点设置屏上，开启中、验证中和出错时 OK 不做任何事（底栏同样不写），关闭后 OK 才重新开启，所以不会中断验证、丢掉暂存的 Wi-Fi 凭据；验证结果只在本次“完成设置”关闭热点之后显示，不显示旧结果。USB 窗口已打开时再进入 USB 设置只显示屏幕，不重新打开（不重生成会话、不重置时间），窗口结束后 OK 重新打开。设备开机不再自动开热点：没有账户时欢迎屏等 OK，恢复出厂后同样。ChatGPT 授权只在开始时占用屏幕，之后各阶段不再把人拉回；取消授权不再关闭 USB 窗口。设置会话中长按下键的提示出现在所有界面的底栏。字体加入 GB 2312 一级汉字 3,755 个和常用全角标点（12、16 像素，仍为 4-bpp 未压缩），备注名和 Wi-Fi 名里的日常中文在设备上直接显示；名称里有字库没有的字（生僻字、表情）时，整个名称在设备上显示为“Wi-Fi N”“DeepSeek N”。设置页本来就接受中文，只按真实字节数限制（32 字节，约 10 个汉字）。
- 恢复出厂顺序：先用一次已提交的擦除删除账户目录（此后设备已是新设备），再擦除其余存储；只删了目录的情况下直接重启，由下次启动清理遗留的凭据槽；擦除目录失败则什么都没删，设备继续使用，设备信息的确认框显示“恢复出厂设置失败”。
- 关闭 LVGL 的 Span 和默认主题（界面用不到），主机预览逐像素对比渲染不变，LVGL 内存峰值下降；调试日志增加 `lvgl_pool`。
- 升级数据影响：无。存储布局不变。

### 升级数据影响

升级后首次启动读取账户目录时自动清理。清理幂等：先把被删账户占用的凭据槽改为墓碑，再清零观察缓存中对应的行，最后以序号加 1 原子提交新目录；中途断电后下次启动重新执行，结果相同。目录没有变化时不写 Flash。

| 数据 | 升级后 |
| --- | --- |
| 设备上的 ChatGPT、DeepSeek 账户及其凭据 | 保留 |
| 前 3 个 Wi-Fi、刷新间隔、息屏时间 | 保留 |
| 当前选中账户 | 保留；若指向被删账户，改为第一个剩余账户，没有剩余账户时置空 |
| Claude 账户、电脑来源的账户 | 删除，缓存的额度数据清零 |
| 待启用账户及其凭据槽 | 删除，凭据槽成为墓碑，缓存的额度数据清零 |
| 待启用的第 4 个 Wi-Fi | 删除 |
| 旧电脑端点、配对令牌和证书 | 删除 |
| 默认 NVS 分区的旧 `ai_quota` 命名空间，portable 分区的旧 `config`、`snapshot` 记录 | 擦除，其余命名空间不动 |
| 没有账户目录的设备（含只有 v1 数据的设备） | 按全新设备处理，没有账户和 Wi-Fi；遗留的凭据槽先改为墓碑 |

## 此前的功能（2026-10-02 至 2026-10-07）

- 设备自主联网：Codex 设备码授权、DeepSeek 密钥验证，凭据存独立 portable NVS 分区，令牌整包原子保存，不重放结果不明的续期。
- 统一账户目录：一份账户、Wi-Fi 和设置，手机通过设备热点打开设置页；USB v2 会话协议与物理两分钟窗口，窗口关闭后已接收的授权与保存继续处理。
- 额度显示：独立 5 小时/7 天窗口，缺失窗口隐藏，真实 0% 保留；可用重置次数与剩余额度；紧凑倒计时；DeepSeek 人民币余额。
- 息屏与按键：自动息屏时关闭 Wi-Fi，首次完整按键操作只亮屏；短按在松手时响应，长按松手不再触发短按；设置精简为账户、刷新间隔、立即刷新、息屏、网络信息和设备设置。
- 时间与电量：SNTP 在三个服务器间回退；状态栏显示按比例填充的绿色电池，不推断充电状态。
- 修复：TLS 动态缓冲、凭据缓冲与授权码交换的内存分配、双栈 HTTP 套接字对 IPv4 客户端的识别、热点忙等待与 USB 会话保活。
