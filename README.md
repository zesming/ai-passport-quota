# AI Passport Quota

FoloToy AI Passport 额度看板：ESP32-C3、240 × 320 屏幕、8 MB Flash、无 PSRAM。展示 ChatGPT（统计 Codex 用量）的额度窗口、重置倒计时、来源提供的可用重置与剩余额度，以及 DeepSeek 人民币余额。缺失窗口隐藏，真实 0% 保留。

Passport 自己联网刷新全部账户，不需要电脑常驻任何服务。

## 配置设备

Passport 保存账户、Wi-Fi 和刷新设置。最多八个账户、三个普通 2.4 GHz Wi-Fi。账户只有两种：ChatGPT（Codex 设备码授权）和 DeepSeek（API 密钥）。

1. 按[开发指南](docs/development/README.md)安装固件。
2. 长按 OK → **设备设置 → 热点**。用第一步二维码或屏幕上的名称、密码连接临时热点。
3. 短按 OK 显示网页二维码，连接热点后扫码。也可进入手动输入步骤，在浏览器输入 `http://192.168.4.1` 和屏幕上的 16 位访问码（`XXXX-XXXX-XXXX-XXXX`）。
4. 添加可联网的 Wi-Fi 或兼容手机热点，再添加 ChatGPT 或 DeepSeek 账户。保存只是接收，行状态显示“待验证”。
5. 点页面底部的“完成设置”。热点会关闭，Passport 联网验证 Wi-Fi 和 DeepSeek 密钥；ChatGPT 需要在 Passport 上授权：手机或电脑恢复互联网连接，打开 Passport 显示的官方授权页并输入验证码。热点设置没有逐项结果页：设备屏幕目前只显示联网和授权进度，逐项“正常 / 验证失败”的屏幕显示随设备界面重设计补上；要立刻看到每一项的结果，请用 USB 设置。

设置页是一份静态网页，无需云端服务，也不写浏览器存储。热点窗口开放十分钟，每次修改补到至少五分钟，总共最多二十分钟；重新打开需要操作设备。连续输错五次访问码，热点会锁定，直到在设备上重新开启。网页不返回 API 密钥或令牌。设备凭据存独立 NVS 分区；本固件未加密 Flash，不能防止物理读取。

Codex 采用官方客户端设备码流程的实验性兼容实现，并非已注册的第三方 OAuth 集成或稳定公开额度 API。展示的是 **Codex 用量**，不代表全部 ChatGPT 消息限制。DeepSeek 只显示人民币总可用余额；余额 API 不提供消费历史、请求次数或累计 Tokens。

### USB 设置

有电脑时可以用 USB 设置，不必加入设备热点。在桌面版 Chrome 或 Edge 里打开设置页（GitHub Pages 的 `zesming.github.io/ai-passport-quota`，或本地保存的 `setup_page.html`），然后按顺序做三步：

1. 用 USB 线连接 Passport。
2. 点页面里的“连接 Passport”，选择它的串口。
3. 在 Passport 上打开 USB 设置（长按 OK → **设备设置 → USB**）。页面显示“请在 Passport 上打开 USB 设置”，并自动连接。

顺序不要反：打开串口可能让 Passport 重启，先开 USB 设置再点“连接”会被重启关掉。USB 设置开两分钟，每次修改补到至少五分钟；到期后串口保持打开，在 Passport 上重新打开 USB 设置，页面会自动再连上。

USB 下“完成设置”不会断开：页面逐项显示验证结果，失败的行可以直接修改，再点“完成设置”只验证待验证和失败的行。例如 Wi-Fi 密码输错时，改好密码再验证即可，不用碰 Passport 的按键。设置页版本与固件版本不一致时，页面会提示升级固件，或打开匹配版本的页面（`/p<协议版本>/`）。

## 使用

上/下键切换账户；短按 OK 刷新或确认；长按 OK 打开设置或返回。长按下键息屏，首次完整功能键操作只亮屏。独立电源键保持硬件长按关机。

刷新间隔支持 1/5/15/30 分钟；自动息屏支持从不、30 秒、1/2/5/10 分钟。息屏关闭 Wi-Fi、停止新网络请求，收到的新凭据仍完成保存。亮屏先显示缓存，再恢复联网；手动刷新或到点时才查询来源。网络、校时状态与账户错误分别显示。

网络信息展示连接状态和已保存的 Wi-Fi 名称。设备设置提供热点和 USB，两者管理同一份账户、网络和设置。

状态栏展示 Wi-Fi、校时后的 UTC+8 时间，以及按实际电量比例填充的绿色电池。绿色仅为样式，不代表已验证的充电状态。企业证书网络与蓝牙网络中转尚未实现，请使用普通 Wi-Fi 或兼容手机热点。

## 升级数据影响

从旧固件升级后首次启动会清理已删除功能的数据，其余数据保留：

| 数据 | 升级后 |
| --- | --- |
| 设备上的 ChatGPT、DeepSeek 账户及其凭据 | 保留 |
| 前 3 个 Wi-Fi、刷新间隔、息屏时间 | 保留 |
| 当前选中账户 | 保留；若它已被删除，改为第一个剩余账户，没有剩余账户时置空 |
| 旧版本支持的其他服务账户、由电脑提供数据的账户 | 删除，缓存的额度数据一并清零 |
| 待启用账户（历史账户）及其凭据 | 删除 |
| 待启用的第 4 个 Wi-Fi | 删除 |
| 电脑采集器端点和配对信息 | 删除 |
| 只有旧版本 v1 数据的设备 | 按全新设备处理，没有账户和 Wi-Fi，需重新设置 |

清理是幂等的：中途断电后，下次启动会继续完成。
